# DORMIS Android

**Dormitory Management Information System** — talabalar turar joyi uchun mobil ilova.

## Yuklab olish

[**Android ilovasini yuklab olish (APK)**](https://github.com/KamolovOgabek/Dormis-Android/releases/latest/download/dormis.apk)

[Rasmiy sayt](https://dormis.uz) · [Versiyalar](https://github.com/KamolovOgabek/Dormis-Android/releases)

1. Yuqoridagi tugma orqali **dormis.apk** faylini yuklab oling.
2. Faylni oching. Telefon so‘rasa, yuklab olgan brauzeringizga ilova o‘rnatishga ruxsat bering.
3. Ilovani o‘rnating va oching.
4. Universitet va yotoqxonani tanlab, mavjud login va parolingiz bilan kiring.

## Talablar

- Android 7.0 va undan yuqori.
- Yangilangan Android System WebView va internet aloqasi.
- iPhone uchun [mobil sayt](https://dormis.uz).

## Imkoniyatlar

Talaba kabinetida arizalar, shartnomalar, to‘lovlar, TTJ ID karta, xona, davomat va boshqa xizmatlar mavjud. Student Office va xodimlar ham yagona kirish oynasidan o‘z kabinetiga kiradi.

Ilova yopilganda sessiya saqlanadi. Chiqish tugmasi ilovaning kirish oynasiga qaytaradi.

## Faylni tekshirish

Har bir versiya yonidagi **SHA256SUMS.txt** fayli APK yaxlitligini tekshirish uchun beriladi.

Bu repository faqat APK va uning xeshini tarqatadi.
